Joe's Collection privacy policy

Last updated: September 21, 2026

The skill stores the collection sharing code supplied by the user, associated only with Amazon's skill-specific user identifier. Amazon stores that setting in the encrypted storage provisioned for the skill.

The code is sent to the collection service only to retrieve the shared checklist requested by the user. The skill does not receive or store voice recordings, names, email addresses, or Amazon account credentials, and it does not sell or share data for advertising.

Saying "forget my sharing code" deletes the saved code for that Alexa user. Collection records remain managed by the collection tracker.
