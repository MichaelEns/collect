Joe's Collection terms of use

Last updated: September 30, 2026

This skill is a private collection aid provided as-is for invited family use. Package-code information comes from collector reports and may be incomplete or disputed. Check the physical package before purchasing.

Keep four-word codes within the family. An owner code can fully manage a collection, a contribute code can change finds and personal photos, and a view code can only read it. Revoke a share code that should no longer work.
